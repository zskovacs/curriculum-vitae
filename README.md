### Project structure

This repository contains the source for [cv.kovacs.id](https://cv.kovacs.id), a static bilingual professional CV site. Node.js renders semantic HTML from the localized content modules, Tailwind CSS builds the stylesheet, and the generated `dist/` directory is the deployable artifact.

- English content: `src/content/en.mjs`
- Hungarian content: `src/content/hu.mjs`
- Page templates: `src/templates/`
- Site styles: `src/styles/site.css`

### Local development

Use Node.js 24 (see `.nvmrc`).

```bash
npm ci
npm test
npm run build
npm run check
npm run preview
npm run test:e2e
```

`npm run check` runs unit tests, validates the localized content, builds the site and validates the generated HTML. Browser tests use Playwright; install its Chromium binary once when necessary:

```bash
npx playwright install chromium
```

### Deployment

Pushing to the default branch triggers the GitHub Pages workflow. It installs dependencies, runs the site checks, builds `dist/` and deploys that generated directory. The custom domain is configured through `public/CNAME`.
